Species names for Perch detections
=================================

`perch_ebird2021_names.csv` contains the species code, English common name,
and scientific name from the official eBird 2021 taxonomy:
https://api.ebird.org/v2/ref/taxonomy/ebird?fmt=csv&version=2021

Retrieved 28 October 2026. The version matches Perch 8's `ebird2021`
namespace. Rows include non-species taxonomic categories as supplied by eBird.
Keep this file alongside the classifier for offline name resolution.
Scientific-name labels from Perch v2 are annotated only when they exactly
match this table. Unmapped labels keep their original label and namespace.
